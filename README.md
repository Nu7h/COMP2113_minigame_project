# COMP2113_minigame_project : THE LEGEND OF HKU

**The game is inspried by The Legend of Zelda**

The purpose of the project is to recreate a source code base for the game from scracth.
The main game will be based on text and dot arts.

## How to Play
Run: 
`make && ./build/game` or `make`


## Basic game settings
` ` is a walkable tile  
`#` is an obstacle (unwalkable)  
`P` is player  
`E` is enermy  
`B` is boss  
`*` is attacking partical  

## Usage and Controls

| Key | Action |
| -------- | -------- |
| W | Up |
| A | Left |
| S | Down |
| D | Right |
| Space bar | Attack |
| P | Pause | 
| Q | Quit |
